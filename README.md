# funny-math

ข้อสอบคณิตศาสตร์ ม.1 — หน้าเว็บแบบไฟล์เดียว (single-file HTML) ทำข้อสอบและตรวจคำตอบได้ในเบราว์เซอร์

## เปิดใช้งาน

👉 [tkosin.github.io/funny-math](https://tkosin.github.io/funny-math/)

## ความสามารถ

- **ตัวกรองด้านซ้าย 4 ชั้น** — หน่วยการเรียนรู้ · ประเภทข้อสอบ · ระดับความยาก · ขอบเขตเนื้อหา
  (จำนวนข้างแต่ละตัวเลือกคือผลลัพธ์ที่จะได้ถ้าเลือกตัวเลือกนั้น) · บนจอเล็กยุบเป็นปุ่ม “🔍 ตัวกรอง”
- **ช่องวิธีทำหลายบรรทัด** — กด Enter หรือ “+ เพิ่มบรรทัด” เพื่อเพิ่มบรรทัด, Shift+Enter ขึ้นบรรทัดในช่องเดิม,
  Backspace ในบรรทัดว่างเพื่อลบ
- **ช่องคำตอบสุดท้าย** — กด “ตรวจคำตอบ” เพื่อเทียบกับเฉลยโดยไม่ต้องเปิดเฉลย ตอบถูกจะติ๊ก “ทำแล้ว” ให้เอง
  เทียบแบบยืดหยุ่น: ไม่สนช่องว่าง/หน่วย (`65` = `65 ตร.ซม.`) · เศษส่วนเทียบทศนิยมได้ · ตัวเลือก `ข` = `ข้อ ข`
- **บันทึกอัตโนมัติ** — วิธีทำ คำตอบ และข้อที่ทำแล้ว เก็บใน `localStorage` รีเฟรชแล้วไม่หาย
- **รูปประกอบเป็น inline SVG** — แผนภูมิแท่ง/เส้น/วงกลม/รูปภาพ, ภาพลูกบาศก์สามมิติ, รูปคลี่ · เปิดออฟไลน์และสั่งพิมพ์ได้
- **เฉลยล็อกด้วยรหัสผ่าน** — ตั้งค่าที่ตัวแปร `ANSWER_PASSWORD` ใน `index.html`
- **พิมพ์เป็นกระดาษ** — พิมพ์เฉพาะข้อที่ตัวกรองเลือกไว้ เลือกได้ว่าจะมีเฉลยหรือไม่

## ไฟล์ในโปรเจกต์

| ไฟล์ | คำอธิบาย |
| --- | --- |
| `index.html` | **ไฟล์หลัก** — GitHub Pages เสิร์ฟไฟล์นี้ (รวมข้อสอบทั้งหมดไว้ในไฟล์เดียว) |
| `ข้อสอบคณิตศาสตร์_ม1.html` | สำเนาชื่อภาษาไทย ไว้ดาวน์โหลด/เปิดออฟไลน์ |
| [`docs/coverage-plan.md`](docs/coverage-plan.md) | แผนขยายคลังข้อสอบเทียบตัวชี้วัด ม.1 + ความคืบหน้า |
| `tools/svg_helpers.py` | ฟังก์ชันสร้างรูป SVG (แผนภูมิ, ภาพสามมิติ, รูปคลี่) |
| `tools/phase1_questions.py` | นิยามข้อสอบเฟส 1 → `questions/phase1.json` |
| `tools/merge_into_html.py` | รวมข้อสอบชุดใหม่เข้า `index.html` (รันซ้ำได้ ข้ามข้อที่ซ้ำ) |

## เพิ่มข้อสอบ

```bash
python3 tools/phase1_questions.py                      # สร้าง questions/phase1.json
python3 tools/merge_into_html.py questions/phase1.json  # รวมเข้า index.html
cp index.html ข้อสอบคณิตศาสตร์_ม1.html                  # ซิงค์สำเนา
```

ดูรายละเอียดหัวข้อที่ยังต้องเพิ่มและหลักการเขียนเฉลยให้ระบบตรวจอัตโนมัติได้ที่
[`docs/coverage-plan.md`](docs/coverage-plan.md)

> ⚠️ การแทรกข้อสอบทำให้เลขข้อเลื่อน ต้องเพิ่มเลขเวอร์ชันของ `STORE_KEY` ใน `index.html`
> (ปัจจุบัน `funnymath-m1-v2`) เพื่อไม่ให้ความก้าวหน้าที่บันทึกไว้จับคู่ผิดข้อ
