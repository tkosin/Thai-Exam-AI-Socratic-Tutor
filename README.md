## โครงหน้าเว็บ

เปิดหน้าแรกโหลดแค่ `index.html` (~217 KB) ซึ่งมีโค้ดกับ **สารบัญวิชา** พอให้แสดงรายชื่อวิชา
ชื่อหน่วย จำนวนข้อรายหน่วย และความก้าวหน้าได้ครบ · **ข้อสอบโหลดตอนกดเข้าวิชานั้น**
จาก `data/<slug>.json` ไฟล์เดียว

| | ก่อน | ตอนนี้ |
| --- | ---: | ---: |
| ดาวน์โหลดตอนเปิดหน้าแรก | 2.34 MB | **0.22 MB** |
| หน้าแรกพร้อมใช้ | 312 ms | **164 ms** |

ความก้าวหน้าอ้างด้วย**รหัสประจำข้อ** และรหัสบอกวิชากับหน่วยอยู่ในตัว หน้าแรกจึงนับ
ความก้าวหน้าของวิชาที่ยังไม่โหลดได้ · **สำเนาชื่อไทยยังรวมทุกอย่างไว้ในไฟล์เดียว**
เพราะเปิดจาก `file://` แล้ว `fetch()` ถูกเบราว์เซอร์บล็อก

**สำเนาออฟไลน์ฝังฟอนต์ไทยไว้ในไฟล์ด้วย** จึงเปิดตอนไม่มีเน็ตแล้วตัวหนังสือยังเป็นฟอนต์เดิม
(เดิมโฆษณาว่าเปิดออฟไลน์ได้ แต่ฟอนต์โหลดจาก Google Fonts จึงตกไปใช้ฟอนต์ระบบ)
· **ไม่ได้ฝังใน `index.html`** เพราะ base64 ราว 152 KB จะดันหน้าแรกจาก 220 เป็น 372 KB
ซึ่งกินผลของการแยกข้อมูลไปเกือบหมด ส่วนสำเนาออฟไลน์ใหญ่ 4.4 MB อยู่แล้ว เพิ่ม 3.6% ไม่มีผล

## ความสามารถ

- **หน้าแรกรวมทุกวิชาไว้ที่เดียว** — เปิดเว็บมาเจอก่อนเสมอ
  - **ปุ่ม “ทำต่อ”** พากลับไปข้อที่ค้างไว้ล่าสุดในคลิกเดียว
  - แถบความก้าวหน้ารวมทุกวิชา · ถูกกี่ข้อ ผิดกี่ข้อ
  - การ์ดของแต่ละวิชาบอกจำนวนข้อ จำนวนหน่วย และความก้าวหน้าของวิชานั้น
  - **ทางลัดไปแต่ละหน่วย** กดแล้วเข้าหน้าข้อสอบพร้อมตั้งตัวกรองหน่วยนั้นให้เลย
  - กลับหน้าแรกได้ตลอดด้วยปุ่ม “🏠 หน้าแรก” บนหัวเรื่อง
- **เลือกวิชาได้จากแผงตัวกรอง** — คณิตศาสตร์ ม.1/ม.2/ม.3 · วิทยาศาสตร์ ม.1/ม.2/ม.3
  แต่ละวิชามีหน่วย ชุดข้อสอบ และเลขข้อเป็นของตัวเอง · จำวิชาที่เลือกไว้ให้
- **ตัวกรองอีก 4 ชั้นภายในวิชา** — หน่วยการเรียนรู้ · ประเภท/ชุดข้อสอบ · ระดับความยาก · ขอบเขตเนื้อหา
  (จำนวนข้างแต่ละตัวเลือกคือผลลัพธ์ที่จะได้ถ้าเลือกตัวเลือกนั้น)
  **แผงตัวกรองซ่อนไว้ตั้งแต่เริ่ม** ให้เห็นข้อสอบเต็มความกว้าง กาง/พับด้วยปุ่ม “🔍 ตัวกรอง” บนหัวเรื่อง
  (หรือ ✕ ในแผง · Esc ปิด) · ตัวเลขบนปุ่มบอกจำนวนตัวกรองที่ใช้อยู่ · จำสถานะกาง/พับไว้ให้
- **ช่องวิธีทำหลายบรรทัด** — กด Enter หรือ “+ เพิ่มบรรทัด” เพื่อเพิ่มบรรทัด, Shift+Enter ขึ้นบรรทัดในช่องเดิม,
  Backspace ในบรรทัดว่างเพื่อลบ
- **ช่องคำตอบสุดท้าย** — กด “ตรวจคำตอบ” เพื่อเทียบกับเฉลยโดยไม่ต้องเปิดเฉลย ตอบถูกจะติ๊ก “ทำแล้ว” ให้เอง
  เทียบแบบยืดหยุ่น: ไม่สนช่องว่าง/หน่วย (`65` = `65 ตร.ซม.`) · เศษส่วนเทียบทศนิยมได้ · ตัวเลือก `ข` = `ข้อ ข`
  **ข้อสอบคณิตศาสตร์ทุกข้อตรวจอัตโนมัติได้** (มีเพียง 17 ข้อทั่วคลังที่เป็นคำตอบเชิงบรรยาย —
  ทั้ง 17 ข้ออยู่ในหน่วยการสร้างทางเรขาคณิต และตอนนี้**มีข้อคู่ขนานที่ตรวจได้ครบทุกทักษะแล้ว**)
- **ระดับความยาก 5 ระดับ** — ง่าย · กลาง · ยาก · **แข่งขัน** · **โอลิมปิก**
  **ทุกหน่วยมีข้อระดับยากขึ้นไปอย่างน้อย 15% ของหน่วยนั้น** — เดิมหน่วยพื้นฐานอย่าง
  จำนวนเต็มหรือเศษส่วนมีข้อ "ยาก" แค่ 3-4 ข้อ กรองแล้วแทบไม่เหลืออะไรให้ทำ (`tools/gen_hard.py`)
  แข่งขัน = แนวสอบแข่ง สพฐ./สสวท./TEDET (**ครบทั้ง 6 วิชา** รวม 366 ข้อ)
  โอลิมปิก = แนว สอวน./TMO ยากกว่าอีกขั้น มักไม่มีสูตรตรง ๆ ให้ใช้
  (คณิตศาสตร์เท่านั้น รวม 86 ข้อ อยู่ในหน่วย “โจทย์ระดับโอลิมปิก”)
  **ข้อสองระดับบนจัดเป็น 49 แม่แบบ แต่ละแม่แบบมีอย่างน้อย 8 ข้อ** กรองด้วยประเภทย่อย
  แล้วได้ชุดฝึกที่ใช้จริงได้ทุกอัน (เดิมกระจายเป็น 133 ประเภทที่ส่วนใหญ่มีข้อเดียว)
  สัดส่วนสองระดับบนอยู่ในช่วงเป้าครบทุกวิชา — ดู [`docs/olympiad-guide.md`](docs/olympiad-guide.md)
  ป้ายสีไล่เข้มขึ้นตามระดับ กวาดสายตาแล้วเห็นทันทีว่าข้อไหนระดับไหน
  `validate.py` บังคับว่าทุกวิชาต้องมีครบทุกระดับ — เดิมบังคับเฉพาะคณิตศาสตร์
  วิทยาศาสตร์จึงไม่มีระดับแข่งขันเลยสักข้อโดยไม่มีใครดัก
- **บันทึกอัตโนมัติ** — วิธีทำ คำตอบ และข้อที่ทำแล้ว เก็บใน `localStorage` รีเฟรชแล้วไม่หาย
  อ้างด้วย**รหัสประจำข้อ ไม่ใช่ลำดับข้อ** จึงเพิ่มข้อใหม่ตรงไหนก็ได้โดยของเก่าไม่เลื่อนไปทับข้ออื่น
  (ของที่บันทึกไว้ก่อนเปลี่ยนระบบถูกย้ายให้อัตโนมัติครั้งเดียวตอนเปิดหน้า)
- **ใช้บนมือถือได้จริง** — จอแคบกว่า 760px ปุ่มบนหัวเรื่องยุบเป็นเมนู **☰** (เดิมห่อลงมา 3-4 แถว
  กินความสูงจอไป ~30% ก่อนจะเห็นโจทย์ · ตอนนี้เหลือ ~11%) · กดปุ่มในเมนูแล้วปิดให้เอง
  ปิดด้วยการกดนอกเมนูหรือ Esc ก็ได้ · การ์ดวิชาในหน้าแรกย่อตามจอ ไม่ต้องเลื่อนแนวนอน
- **รูปประกอบเป็น inline SVG** 144 รูป ใช้จริงใน 480 ข้อ — แผนภูมิแท่ง/เส้น/วงกลม/รูปภาพ,
  ลูกบาศก์สามมิติ, รูปคลี่, สามเหลี่ยมมุมฉาก, ระนาบพิกัดสำหรับการแปลงทางเรขาคณิต,
  ปริซึม/ทรงกระบอก, แผนภาพจุด, ฮิสโทแกรม,
  **แผนภาพกล่อง, พาราโบลา, เส้นจำนวนของอสมการ, พีระมิด/กรวย/ทรงกลม, รูปคล้าย, วงกลม,
  วงจรไฟฟ้า, แผนภาพรังสีแสง, คลื่น, ตารางพันเนตต์, สายใยอาหาร, แบบจำลองอนุภาค,
  แผนภาพแรง, ผังลำดับ, สเปกตรัม, ปริซึม, วงโคจร, ข้างขึ้นข้างแรม,
  กราฟให้ความร้อน, แบบจำลองอะตอม/ธาตุ/สารประกอบ, ชั้นบรรยากาศ/ชั้นดิน/น้ำใต้ดิน,
  โครงสร้างภายในโลก, การกระจัด, รอยวงเวียนของการสร้างทางเรขาคณิต** · สั่งพิมพ์ได้
  ตัวเลขบนรูปกับในโจทย์มาจากตารางเดียวกัน จึงบอกคนละเลขไม่ได้
  **ทุกตัวชี้วัดที่หลักสูตรสั่งให้ใช้รูป (เขียนแผนภาพ · เขียนกราฟ · แบบจำลอง) มีรูปครบแล้วทั้ง 6 วิชา**
  **ชีววิทยาไม่มีรูปวาดโครงสร้าง** — เซลล์ อวัยวะ และสิ่งมีชีวิตวาดด้วย SVG แล้วไม่เหมือนของจริง
  ใช้เฉพาะตารางกับผังที่ไม่ได้วาดของจริง (ตารางพันเนตต์ · สายใยอาหาร · ผังทางเดินของเลือด/อากาศ)
- **เฉลยล็อกด้วยรหัสผ่าน** — ตั้งค่าที่ตัวแปร `ANSWER_PASSWORD` ใน `index.html`
  (เป็นเพียงที่กั้นไม่ให้เผลอกด ไม่ใช่ความปลอดภัย — เฉลยอยู่ในซอร์สของหน้าเว็บ)
- **“พี่หลวง” ติวเตอร์ AI แบบโสกราตีส** — แช็ตรายข้อที่ช่วยด้วยการ *ถามคำถามนำ* ให้คิดออกเอง ไม่บอกคำตอบตรง ๆ
  · บุคลิกรุ่นพี่ผู้ชาย เรียกตัวเองว่า “พี่” เรียกผู้เรียนว่า “น้อง” ลงท้าย “ครับ/ครับน้อง”
  · เปิดเป็น **แผงเลื่อนออกจากขอบขวา** เบียดเนื้อหาไปทางซ้ายให้เห็นโจทย์ครบ (จอแคบกางเต็มจอ) · ปิดด้วย ✕ หรือ Esc
  · พี่หลวงเห็นวิธีทำที่เขียนไว้ทุกบรรทัดจึงชี้จุดที่พลาดได้ตรงจุด
  · **ตรวจโจทย์กับเฉลยให้ด้วยทุกครั้ง** — ถูกก็สอนต่อเงียบ ๆ ถ้าเจอว่าเฉลยผิดหรือโจทย์ข้อมูลไม่ครบ
  จะขึ้นกล่องเตือนบอกนักเรียน (ด่านสุดท้ายเสริมจาก `verify_math.py` ที่ตรวจได้แค่บางส่วน)
  · แสดง **สมการจริง** (`2^2` → 2² · `3/4` เป็นเศษส่วนซ้อน) และ **วาดรูป SVG ประกอบ** ได้เมื่อจำเป็น
  (เส้นจำนวน · รูปเรขาคณิต · กราฟ) โดยกรองรูปด้วยรายการแท็ก/แอตทริบิวต์ที่อนุญาตก่อนแสดง
  · **คำใบ้ปล่อยทีละขั้น 7 ขั้น** ยิ่งถามยิ่งละเอียด · ขั้นเฉลยเต็มต้องปลดล็อกด้วยรหัสผ่านเดียวกับ “ดูเฉลย”
  · ต้องใส่ **API key ของตัวเอง** (เก็บใน `localStorage` เครื่องนั้น) เพราะเว็บนี้ไม่มีเซิร์ฟเวอร์
  · ใช้ได้ทั้ง **Anthropic (Claude) · OpenAI (ChatGPT) · Google (Gemini)** และบริการแบบ
  OpenAI-compatible (OpenRouter, Groq, Ollama ในเครื่อง) — คีย์เก็บแยกเจ้า สลับไปมาได้
  · รายละเอียด: [`docs/ai-tutor.md`](docs/ai-tutor.md)
- **พิมพ์เป็นกระดาษ** — พิมพ์เฉพาะข้อที่ตัวกรองเลือกไว้ เลือกได้ว่าจะมีเฉลยหรือไม่

## แก้ไขและเพิ่มข้อสอบ

ข้อสอบแยกเป็นไฟล์ละหน่วยในโฟลเดอร์ของแต่ละวิชา — แก้ไฟล์ของหน่วยนั้นแล้ว build

```bash

python3 tools/build.py                                  # ประกอบเข้า index.html + ซิงค์สำเนา

```

### ฟิลด์ `explain` — คำอธิบายวิธีคิด

ข้อสอบมีฟิลด์ `explain` ได้ · หน้าเว็บแสดงทันทีที่กด "ตรวจคำตอบ" **ทั้งตอนถูกและตอนผิด
และไม่ต้องใส่รหัสผ่าน** — รหัสผ่านยังกั้น *ตัวเฉลย* ไว้เหมือนเดิม แต่คำอธิบายที่ล็อกไว้หลัง
รหัสผ่านที่นักเรียนไม่มี เท่ากับไม่มีคำอธิบาย และคนที่เดาถูกก็ยังควรได้รู้ว่าทำไม

`validate.py` ตรวจคุณภาพให้ ไม่ใช่แค่ว่ามีฟิลด์ — ต้องยาวอย่างน้อย 40 ตัวอักษร และ
**ห้ามเป็นการทวนข้อความของตัวเลือกที่ถูกเฉย ๆ** · วิชาที่ตั้ง `explain_required: true`
ใน `topics.json` จะถูกบังคับทุกข้อ ส่วนวิชาที่ยังไม่ตั้งจะรายงานความคืบหน้าไว้เฉย ๆ

คลังเดิม 5,175 ข้อยังไม่มีคำอธิบาย — ชุดนำร่องคือเทคโนโลยี ม.3 หน่วยที่ 1 (18 ข้อ)
ลำดับการทยอยเติมอยู่ใน [`docs/implementation-plan.md`](docs/implementation-plan.md)

`tools/check.sh` รวมทุกขั้นไว้ให้แล้ว — ตรวจว่าคลังรูปตรงกับสคริปต์ที่สร้างมัน ·
`index.html` ตรงกับคลังข้อสอบ · `validate.py` · **`verify_math.py`** · `dom_test.cjs`
(ลง `jsdom` ให้เองครั้งแรก) ผ่านทุกขั้นถึงจะคืนสถานะ 0 · จะรันแยกทีละขั้นก็ได้

`verify_math.py` มีไว้เพราะ `validate.py` ตรวจได้แค่ว่า "กรอกค่าตรงเฉลยแล้วระบบว่าถูก" —
ถ้าตัวสร้างข้อสอบใช้สูตรผิด เฉลยก็ผิดตามกันทั้งชุดโดยไม่มีใครจับได้ ไฟล์นี้จึง**อ่านจากตัวโจทย์
แล้วคิดใหม่ด้วยวิธีที่ไม่เหมือนตัวสร้าง** (ไล่ค่าดิบ ๆ แทนสูตรปิด · กระจายพหุนามที่แยกตัวประกอบ
แล้วเทียบสัมประสิทธิ์ · ประเมินนิพจน์เลขคณิตด้วย `ast` ไม่ใช่ `eval`) แล้วเทียบกับเฉลย

ครอบคลุม **2,714 จาก 5,175 ข้อ** — คิดเป็น **98% ของข้อคณิตศาสตร์ที่คิดใหม่เป็นตัวเลขได้**
ที่เหลือรายงานไว้ตรง ๆ ว่าทำไมยังตรวจไม่ได้ — 1,922 ข้อเป็นวิชาอื่น (ตัวตรวจนี้ดูเฉพาะ
คณิตศาสตร์) · 190 ข้อตัวเลขอยู่ในรูป อ่านจากข้อความไม่ได้ · 183 ข้อเฉลยเป็นข้อความจึงคิดใหม่
เป็นตัวเลขไม่ได้เลย · 93 ข้อเป็นปรนัยเชิงนิยาม · เหลือที่ยังเขียนกฎได้อีก **4 ข้อ**
สามถังกลางเป็นถังปิด ไม่ใช่งานค้าง

ยอดรวมของทุกถังต้องเท่ากับจำนวนข้อที่เดินผ่านพอดี ไม่งั้นตัวตรวจฟ้องเอง
(เคยมีบั๊กที่นับข้อเดียวสองถังจนตัวเลขในรายงานสูงกว่าคลังจริง)

กฎใน `RULES` จับคู่**ตามลำดับที่ประกาศ และหยุดที่กฎแรกที่ตรง** กฎของตระกูลแคบจึงต้องอยู่
ก่อนกฎกว้างอย่าง `^จงหาค่าของ …` เสมอ — เคยเขียนกฎกว้างไว้ก่อนแล้วมันแย่งข้อที่กฎอ่านค่า
จากรูปดูแลอยู่ ผลคือจำนวนข้อที่ตรวจได้**ลดลง**ทั้งที่เพิ่งเพิ่มกฎเข้าไป

ตัวตรวจเองมี `selftest()` ที่รันก่อนทุกครั้ง เพราะเคยมีบั๊กที่ครอบวงเล็บจนลำดับ
การดำเนินการเพี้ยน และบั๊กที่เครื่องหมายลบผูกแน่นกว่าเลขยกกำลัง (`-x²` กลายเป็น `(-x)²`
ทำให้พาราโบลาคว่ำทุกเส้นอ่านสัมประสิทธิ์ผิดเครื่องหมาย)

```bash
python3 tools/build.py --check                          # ตรวจว่าไฟล์ตรงกับคลังข้อสอบ
python3 tools/validate.py                               # ตรวจคลังข้อสอบ
python3 tools/verify_math.py                            # ตรวจว่าเฉลยคณิตถูกจริง
npm install jsdom --no-save && node tools/dom_test.cjs  # ทดสอบหน้าเว็บ
```

**ตรวจเลย์เอาต์บนขนาดจอจริง** (ไม่ได้อยู่ใน `check.sh` เพราะต้องลงเบราว์เซอร์ ~100 MB)

```bash
npm install playwright --no-save && npx playwright install chromium
node tools/responsive_check.js        # 8 ขนาดจอ ตั้งแต่ 360px ถึง 1920px
```

`dom_test.cjs` รันบน jsdom ซึ่ง**ไม่จัดเลย์เอาต์** จึงวัดความกว้าง/ตำแหน่งไม่ได้เลย
ตรวจได้แค่ว่ากฎ CSS ยังอยู่ครบ · ไฟล์นี้เปิดหน้าจริงแล้ววัดของจริง

**แผนที่หัวข้อ (`questions/topics.json`)** — บอกว่าแต่ละวิชาต้องมีข้อสอบของตัวชี้วัดใดบ้าง
`validate.py` ใช้ไฟล์นี้ตัดสิน: หัวข้อ `status: active` ที่ไม่มีข้อสอบ = **ตรวจไม่ผ่าน**
หัวข้อ `status: planned` คือของที่ตั้งใจว่ายังไม่ทำ ถ้าดันมีข้อสอบแล้วก็ตรวจไม่ผ่านเช่นกัน
(แปลว่าลืมอัปเดตแผนที่) และตัวชี้วัดที่มีข้อสอบแต่ไม่มีในแผนที่ก็ไม่ผ่าน
`subtopics` ใช้ตรวจละเอียดกว่าระดับตัวชี้วัด — เช่น ค 3.1 ม.3/1 มีควอร์ไทล์ครบแล้ว
แต่ยังไม่มีแผนภาพกล่อง/เปอร์เซ็นไทล์/ค่านอกเกณฑ์ ซึ่งอยู่ในตัวชี้วัดเดียวกัน

**เพิ่มวิชาใหม่** — สร้างโฟลเดอร์ `questions/<slug>/` ใส่ไฟล์ `unit-*.json`
แล้ว**ต่อท้าย** `questions/courses.json` (ห้ามแทรกไว้ก่อนวิชาเดิม ดูหัวข้อถัดไป)
ทุกวิชาที่มีข้อสอบต้องมีรายการหัวข้อใน `questions/topics.json` ด้วย ไม่งั้นตรวจไม่ผ่าน
ลำดับที่ผู้เรียนเห็นในแผงตัวกรองเรียงตาม `SUBJECT_ORDER` ใน `index.html` แยกจากลำดับในไฟล์ manifest
จึงต่อท้ายได้โดยไม่ต้องยอมให้วิชาใหม่ไปอยู่ท้ายรายการในหน้าเว็บ

### ตรวจก่อน push โดยไม่ใช้ GitHub Actions

repo นี้ **ไม่มี workflow ของ Actions เลย** — ทั้งการตรวจและการ deploy ไม่ต้องใช้ runner
จึงไม่กินโควตาและไม่ต้องมีวงเงิน (Pages เสิร์ฟจากแบรนช์ ดูหัวข้อถัดไป)

ให้ตรวจอัตโนมัติทุกครั้งที่ `git push` ด้วยการเปิด git hook ในเครื่องครั้งเดียว

```bash
bash tools/check.sh --install     # = git config core.hooksPath .githooks
```

จากนั้น `.githooks/pre-push` จะรัน `tools/check.sh` ให้ก่อนทุกครั้ง ถ้าไม่ผ่านจะไม่ push
(ข้ามครั้งเดียวด้วย `git push --no-verify` · เลิกใช้ด้วย `git config --unset core.hooksPath`)

ข้อแลกเปลี่ยนที่ต้องรู้: hook อยู่ในเครื่องของแต่ละคน ไม่ได้บังคับจากฝั่ง GitHub
ใครยังไม่รัน `--install` ก็ push ได้โดยไม่ถูกตรวจ — เหมาะกับ repo ที่ดูแลกันไม่กี่คน
ถ้าวันหนึ่ง Actions ของบัญชีใช้ได้แล้วและอยากบังคับจากฝั่งเซิร์ฟเวอร์ ค่อยเพิ่ม workflow
ที่รัน `bash tools/check.sh` ขั้นเดียวก็พอ

## การเผยแพร่ (GitHub Pages)

Pages ตั้งเป็นแบบ **Deploy from a branch** → `main` / `/ (root)`
push เข้า `main` แล้ว GitHub เอาไฟล์ในแบรนช์ไปเสิร์ฟให้เอง **ไม่ผ่าน Actions ของบัญชี
จึงไม่กินโควตาและไม่ต้องมีวงเงิน** (ไฟล์ `.nojekyll` ที่ราก บอกให้เสิร์ฟไฟล์ตามจริงโดยไม่ผ่าน Jekyll)

ตั้งค่าที่ **Settings → Pages → Build and deployment → Source: Deploy from a branch**
เลือก `main` และโฟลเดอร์ `/ (root)`

> เดิมเคย deploy ด้วย `actions/deploy-pages` ซึ่งต้องรัน job บน Actions — ถ้า Actions ของบัญชี
> ใช้ไม่ได้ (โควตาหมด/ปัญหาการชำระเงิน/ถูกระงับ) เว็บจะค้างเวอร์ชันเก่าทั้งที่โค้ดเข้า `main` แล้ว
> แบบ branch จึง deploy ได้แม้ Actions ใช้ไม่ได้
>
> งาน `pages build and deployment` ที่ขึ้นในแท็บ Actions หลัง push ไม่ใช่ workflow ของ repo
> แต่เป็นของ GitHub เอง ลบไม่ได้และ**ไม่กินโควตาของบัญชี**

### รู้ได้อย่างไรว่า deploy ขึ้นแล้ว

```bash
bash tools/pages_status.sh          # เทียบไฟล์ที่ push ล่าสุดแก้ + index.html
bash tools/pages_status.sh --all    # เทียบไฟล์ข้อมูลรายวิชาทุกไฟล์ด้วย
bash tools/pages_status.sh --watch  # push แล้วปล่อยรอ วนเช็กจนตรง
```

**"build ผ่าน" ไม่ได้แปลว่า "ผู้เรียนเห็นของใหม่แล้ว"** — หน้าเว็บส่ง `cache-control: max-age=600`
ขอบ CDN และเบราว์เซอร์จึงคืนของเดิมได้อีกถึง 10 นาทีหลัง deploy สำเร็จ สคริปต์นี้เลย
ไม่ดูสถานะ build แต่**ดึงไฟล์จริงมาเทียบกับไฟล์ใน `main` ทีละไบต์** ซึ่งเป็นคำถามที่อยากรู้จริง ๆ

รายการไฟล์ที่เทียบมาจาก **`git diff` ของ push ล่าสุด** ไม่ใช่รายการตายตัว — ถ้าเทียบแต่
`index.html` แล้ว push นั้นไม่ได้แตะ `index.html` (เช่นแก้แต่เอกสารหรือสคริปต์) จะได้
เครื่องหมายถูกทันทีตั้งแต่ยังไม่ deploy ซึ่งเป็น**คำตอบที่ผ่านโดยไม่มีหลักฐาน**
ไฟล์ที่ถูกลบก็ตรวจกลับด้าน — deploy สำเร็จแปลว่าเว็บต้องไม่มีไฟล์นั้นแล้ว

ตัวเลขที่วัดได้จากงาน `pages build and deployment` 8 รอบล่าสุด: สำเร็จทุกรอบ **ใช้เวลา 25–30 วินาที**
ดังนั้นถ้าเกินสองนาทีแล้วยังไม่ตรง ให้ไปดูแท็บ Actions ว่างานล้มหรือยังไม่ได้เริ่ม

สคริปต์นี้**ไม่อยู่ใน `tools/check.sh`** เพราะต้องต่อเน็ตและตอบเรื่องหลัง push
ส่วน `check.sh` เป็นด่านก่อน push ที่ต้องรันได้แบบออฟไลน์
