# funny-math

ข้อสอบคณิตศาสตร์ ม.1 · 200 ข้อ — หน้าเว็บแบบไฟล์เดียว (single-file HTML) ทำข้อสอบได้ในเบราว์เซอร์

## เปิดใช้งาน

👉 https://tkosin.github.io/funny-math/

## ไฟล์ในโปรเจกต์

| ไฟล์ | คำอธิบาย |
|---|---|
| `index.html` | **ไฟล์หลัก** — แก้ไขที่นี่ · GitHub Pages เสิร์ฟไฟล์นี้ |
| `ข้อสอบคณิตศาสตร์_ม1_200ข้อ.html` | สำเนาชื่อภาษาไทย ไว้ดาวน์โหลด/เปิดออฟไลน์ |

> แก้ที่ `index.html` แล้วซิงค์สำเนา:
> `cp index.html ข้อสอบคณิตศาสตร์_ม1_200ข้อ.html`

## ความสามารถ

- **ตัวกรองด้านซ้าย** — กรองตามหน่วยการเรียนรู้ (9 หน่วย) และประเภทข้อสอบ (38 ประเภท) บนจอเล็กยุบเป็นปุ่ม “🔍 ตัวกรอง”
- **ช่องวิธีทำหลายบรรทัด** — กด Enter หรือ “+ เพิ่มบรรทัด” เพื่อเพิ่มบรรทัด, Shift+Enter ขึ้นบรรทัดในช่องเดิม, Backspace ในบรรทัดว่างเพื่อลบ
- **ช่องคำตอบสุดท้าย** — กด “ตรวจคำตอบ” เพื่อเทียบกับเฉลยโดยไม่ต้องเปิดเฉลย ตอบถูกจะติ๊ก “ทำแล้ว” ให้เอง
  (เทียบแบบยืดหยุ่น: ไม่สนช่องว่าง/หน่วย เช่น `65`, `65 ตร.ซม.` ถือว่าเท่ากัน · เศษส่วนเทียบกับทศนิยมได้ · ข้อที่เป็นคำตอบเชิงอธิบายจะแจ้งให้เทียบเฉลยเอง)
- **บันทึกอัตโนมัติ** — วิธีทำ คำตอบ และข้อที่ทำแล้ว เก็บใน `localStorage` ของเครื่อง รีเฟรชแล้วไม่หาย
- **เฉลยล็อกด้วยรหัสผ่าน** — ตั้งค่าที่ตัวแปร `ANSWER_PASSWORD` ใน `index.html`
