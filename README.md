# funny-math

ข้อสอบคณิตศาสตร์ ม.1 · 200 ข้อ — หน้าเว็บแบบไฟล์เดียว (single-file HTML) ทำข้อสอบได้ในเบราว์เซอร์

## เปิดใช้งาน

👉 https://tkosin.github.io/funny-math/

## ไฟล์ในโปรเจกต์

| ไฟล์ | คำอธิบาย |
|---|---|
| `index.html` | ไฟล์ที่ GitHub Pages ใช้เสิร์ฟ (สำเนาของไฟล์ต้นฉบับ) |
| `ข้อสอบคณิตศาสตร์_ม1_200ข้อ.html` | ไฟล์ต้นฉบับ |

> เมื่อแก้ไขเนื้อหา ให้แก้ไฟล์ต้นฉบับแล้วคัดลอกทับ `index.html`
> `cp ข้อสอบคณิตศาสตร์_ม1_200ข้อ.html index.html`
