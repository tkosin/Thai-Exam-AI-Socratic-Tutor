# math-is-fun

ข้อสอบคณิตศาสตร์ ม.1 · 610 ข้อ ครอบคลุมตัวชี้วัดครบทั้ง 9 ตัว — หน้าเว็บแบบไฟล์เดียว (single-file HTML) ทำข้อสอบและตรวจคำตอบได้ในเบราว์เซอร์

## เปิดใช้งาน

👉 [tkosin.github.io/math-is-fun](https://tkosin.github.io/math-is-fun/)

## ความสามารถ

- **ตัวกรองด้านซ้าย 4 ชั้น** — หน่วยการเรียนรู้ · ประเภทข้อสอบ · ระดับความยาก · ขอบเขตเนื้อหา
  (จำนวนข้างแต่ละตัวเลือกคือผลลัพธ์ที่จะได้ถ้าเลือกตัวเลือกนั้น)
  **แผงตัวกรองซ่อนไว้ตั้งแต่เริ่ม** ให้เห็นข้อสอบเต็มความกว้าง กาง/พับด้วยปุ่ม “🔍 ตัวกรอง” บนหัวเรื่อง
  (หรือ ✕ ในแผง · Esc ปิด) · ตัวเลขบนปุ่มบอกจำนวนตัวกรองที่ใช้อยู่ · จำสถานะกาง/พับไว้ให้
- **ช่องวิธีทำหลายบรรทัด** — กด Enter หรือ “+ เพิ่มบรรทัด” เพื่อเพิ่มบรรทัด, Shift+Enter ขึ้นบรรทัดในช่องเดิม,
  Backspace ในบรรทัดว่างเพื่อลบ
- **ช่องคำตอบสุดท้าย** — กด “ตรวจคำตอบ” เพื่อเทียบกับเฉลยโดยไม่ต้องเปิดเฉลย ตอบถูกจะติ๊ก “ทำแล้ว” ให้เอง
  เทียบแบบยืดหยุ่น: ไม่สนช่องว่าง/หน่วย (`65` = `65 ตร.ซม.`) · เศษส่วนเทียบทศนิยมได้ · ตัวเลือก `ข` = `ข้อ ข`
- **บันทึกอัตโนมัติ** — วิธีทำ คำตอบ และข้อที่ทำแล้ว เก็บใน `localStorage` รีเฟรชแล้วไม่หาย
- **รูปประกอบเป็น inline SVG** — แผนภูมิแท่ง/เส้น/วงกลม/รูปภาพ, ภาพลูกบาศก์สามมิติ, รูปคลี่ · เปิดออฟไลน์และสั่งพิมพ์ได้
- **เฉลยล็อกด้วยรหัสผ่าน** — ตั้งค่าที่ตัวแปร `ANSWER_PASSWORD` ใน `index.html`
- **พิมพ์เป็นกระดาษ** — พิมพ์เฉพาะข้อที่ตัวกรองเลือกไว้ เลือกได้ว่าจะมีเฉลยหรือไม่

## ไฟล์ในโปรเจกต์

| ไฟล์ | คำอธิบาย |
| --- | --- |
| `index.html` | **ไฟล์หลัก** — GitHub Pages เสิร์ฟไฟล์นี้ (รวมข้อสอบทั้งหมดไว้ในไฟล์เดียว) |
| `ข้อสอบคณิตศาสตร์_ม1.html` | สำเนาชื่อภาษาไทย ไว้ดาวน์โหลด/เปิดออฟไลน์ |
| [`docs/coverage-plan.md`](docs/coverage-plan.md) | แผนขยายคลังข้อสอบเทียบตัวชี้วัด ม.1 + ความคืบหน้า |
| `questions/units/*.json` | **คลังข้อสอบ แยกไฟล์ตามหน่วยการเรียนรู้** — แก้ข้อสอบที่นี่ |
| `questions/figures.json` | คลังรูป SVG อ้างด้วยชื่อ ใช้ซ้ำได้หลายข้อ |
| `tools/build.py` | ประกอบคลังข้อสอบ + รูป เข้า `index.html` (และซิงค์สำเนา) |
| `tools/build_figures.py` · `svg_helpers.py` | สร้างคลังรูป (แผนภูมิ, ภาพสามมิติ, ระนาบพิกัด ฯลฯ) |
| `tools/validate.py` · `tools/dom_test.cjs` | ชุดตรวจที่ CI ใช้ (คลังข้อสอบ + พฤติกรรมหน้าเว็บ) |

## แก้ไขและเพิ่มข้อสอบ

ข้อสอบแยกเป็นไฟล์ละหน่วยใน `questions/units/` — แก้ไฟล์ของหน่วยนั้นแล้ว build

```bash
$EDITOR questions/units/unit-07-ratio-proportion-percent.json
python3 tools/build.py                                  # ประกอบเข้า index.html + ซิงค์สำเนา

python3 tools/build.py --check                          # ตรวจว่าไฟล์ตรงกับคลังข้อสอบ
python3 tools/validate.py                               # ตรวจคลังข้อสอบ
npm install jsdom --no-save && node tools/dom_test.cjs  # ทดสอบหน้าเว็บ
```

ทุก pull request จะถูกตรวจด้วยชุดเดียวกันนี้ผ่าน GitHub Actions
(`.github/workflows/pages.yml`) และเมื่อ merge เข้า `main` แล้วจะ deploy GitHub Pages ให้อัตโนมัติ

ดูรายละเอียดหัวข้อที่ยังต้องเพิ่มและหลักการเขียนเฉลยให้ระบบตรวจอัตโนมัติได้ที่
[`docs/coverage-plan.md`](docs/coverage-plan.md)
