# พี่หลวง — ติวเตอร์ AI แบบโสกราตีส

แช็ตช่วยติวรายข้อในหน้าข้อสอบ · ช่วยด้วยการ **ถามคำถามนำ** ให้น้องคิดออกเอง
ไม่ใช่บอกคำตอบให้ · คำใบ้ปล่อยทีละขั้นตามจำนวนครั้งที่ถาม

## บุคลิก

ติวเตอร์ชื่อ **“พี่หลวง”** — รุ่นพี่ผู้ชาย เรียกตัวเองว่า “พี่” เรียกผู้เรียนว่า “น้อง”
ลงท้ายด้วย **“ครับ” / “ครับน้อง”** และห้ามใช้คำลงท้ายแบบผู้หญิงหรือคำเอ็นดูเด็กเล็ก
(“จ๊ะ” “จ้า” “ค่ะ” “นะคะ” “หนู”)

เปลี่ยนชื่อได้ที่ตัวแปร `AI_NAME` ใน `index.html` — ชื่อนี้ใช้ทั้งในพรอมป์ระบบและบนหน้าเว็บ
(ปุ่ม “💬 ถามพี่หลวง”, หัวแผง, ข้อความแจ้งข้อผิดพลาด) ถ้าเปลี่ยนชื่อ อย่าลืมแก้กติกาการตอบ
ในฟังก์ชัน `buildSystem()` ให้สรรพนามและคำลงท้ายเข้ากับบุคลิกใหม่ด้วย

## ใช้งาน

1. กด **🤖 ตั้งค่าพี่หลวง** บนหัวเรื่อง (หรือปุ่มในแผงพี่หลวง)
2. เลือกผู้ให้บริการ AI แล้วใส่ API key ของตัวเอง — ใช้ได้ **4 ทาง**

   | ผู้ให้บริการ | ขอคีย์ที่ | คีย์หน้าตา |
   | --- | --- | --- |
   | Anthropic (Claude) | [console.anthropic.com](https://console.anthropic.com/settings/keys) | `sk-ant-...` |
   | OpenAI (ChatGPT) | [platform.openai.com](https://platform.openai.com/api-keys) | `sk-...` |
   | Google (Gemini) | [aistudio.google.com](https://aistudio.google.com/apikey) | `AIza...` |
   | OpenAI-compatible อื่น ๆ | OpenRouter, Groq, หรือ Ollama ในเครื่อง — กรอก Base URL กับชื่อโมเดลเอง | ตามบริการนั้น |

   คีย์เก็บ**แยกเจ้า** สลับผู้ให้บริการไปมาได้โดยคีย์ที่ใส่ไว้ไม่หาย
3. เลือกโมเดล (ค่าเริ่มต้น: Claude Opus 5 / GPT-5.1 / Gemini 2.5 Flash ตามเจ้าที่เลือก)
4. ในแต่ละข้อ กด **💬 ถามพี่หลวง** แล้วพิมพ์ถาม (Enter = ส่ง · Shift+Enter = ขึ้นบรรทัด)

> Gemini มีโควตาฟรีรายวัน เหมาะสำหรับลองใช้ก่อนโดยไม่ต้องเติมเงิน
> ส่วน Ollama ในเครื่อง (Base URL `http://localhost:11434/v1`) ไม่มีค่าใช้จ่ายเลย
> แต่หน้าเว็บต้องเปิดจากไฟล์ในเครื่องหรือ localhost ด้วยกัน ไม่งั้นเบราว์เซอร์บล็อก mixed content

## แผงพี่หลวง

เป็น **แผงเลื่อนออกจากขอบขวา** อยู่ใต้หัวเรื่อง เต็มความสูงจอ และบทสนทนาเลื่อนดูได้ในตัวแผง
ช่องพิมพ์ถามตรึงอยู่ล่างสุดเสมอ

- **จอกว้างกว่า 1100px** — แผงกว้าง 400px และ *เบียดเนื้อหาไปทางซ้าย* ให้เห็นโจทย์ครบไม่ถูกทับ
  (ถ้าแผงตัวกรองกางอยู่บนจอไม่กว้างพอ จะพับตัวกรองให้เอง)
- **จอแคบกว่านั้น** — กางทับเต็มความกว้างเหมือน drawer
- ปิดด้วยปุ่ม **✕** ในแผง, ปุ่ม **💬 ปิดพี่หลวง** ในการ์ดข้อสอบ, หรือกด **Esc**
- แผงจำสถานะกาง/พับไว้ · เปลี่ยนข้อแล้วแผงตามไปข้อใหม่ให้เอง (ถ้ากำลังพิมพ์คำตอบค้างอยู่จะยกเลิกให้)
- กลับหน้าแรกแล้วแผงจะซ่อนไว้ก่อน แต่ยังจำว่าเคยกางไว้

เขียนวิธีทำในช่อง “วิธีทำ” และกรอกคำตอบไว้ก่อนถาม จะช่วยได้ตรงจุดกว่า
เพราะพี่หลวงเห็นทุกบรรทัดที่เขียนไว้และรู้ว่าตรวจแล้วถูกหรือผิด

## ทำไมต้องใส่คีย์เอง (BYOK)

หน้าเว็บนี้เป็น **ไฟล์เดียวเสิร์ฟจาก GitHub Pages** ไม่มีเซิร์ฟเวอร์ของตัวเอง
จึงไม่มีที่ปลอดภัยให้เก็บคีย์ฝั่งเซิร์ฟเวอร์ และ **ห้ามฝังคีย์ไว้ในซอร์สของ `index.html`**
เพราะซอร์สของหน้าเว็บใครก็เปิดอ่านได้ (ต่างจาก `ANSWER_PASSWORD` ที่เป็นแค่ที่กั้นไม่ให้เผลอกดดูเฉลย)

เบราว์เซอร์จึงเรียก API ของเจ้าที่เลือกตรง ๆ ด้วยคีย์ของผู้ใช้เอง (ทุกเจ้าเปิด CORS ให้เรียกได้)

| เจ้า | endpoint | การยืนยันตัว |
| --- | --- | --- |
| Anthropic | `api.anthropic.com/v1/messages` | `x-api-key` + `anthropic-dangerous-direct-browser-access: true` |
| OpenAI | `api.openai.com/v1/chat/completions` | `Authorization: Bearer` |
| Gemini | `generativelanguage.googleapis.com/…:streamGenerateContent?alt=sse` | `x-goog-api-key` |
| OpenAI-compatible | `<base URL>/chat/completions` | `Authorization: Bearer` |

| เรื่อง | รายละเอียด |
| --- | --- |
| คีย์เก็บที่ไหน | `localStorage` คีย์ `funnymath-ai-v1` ของเบราว์เซอร์เครื่องนั้น เก็บแยกเจ้า · ส่งไปเฉพาะ API ของเจ้าที่เลือกเท่านั้น |
| บทสนทนาเก็บที่ไหน | `localStorage` คีย์ `funnymath-chat-v2` แยกตามข้อ (อ้างด้วยรหัสประจำข้อ) · จำกัดไว้ ~180 KB และ 24 ข้อความต่อข้อ ถ้าเกินจะตัดของเก่าทิ้ง |
| ส่งอะไรไปที่ API | โจทย์ (แปลงเป็นข้อความล้วน) · เฉลย · วิธีทำและคำตอบที่ผู้เรียนกรอก · บทสนทนาของข้อนั้น — ไปที่เจ้าที่เลือกไว้เจ้าเดียว |
| ค่าใช้จ่าย | เรียกเก็บจากคีย์ของผู้ใช้เอง |
| ข้อจำกัด | ไม่เหมาะกับเครื่องที่ใช้ร่วมกันหลายคน และไม่เหมาะแจกให้นักเรียนทั้งห้องใช้ (ทุกคนต้องมีคีย์ของตัวเอง) |

ถ้าต้องการให้นักเรียนหลายคนใช้ร่วมกันโดยไม่ต้องมีคีย์คนละอัน ต้องเพิ่ม **serverless proxy**
(เช่น Cloudflare Worker) ที่เก็บคีย์ไว้ฝั่งเซิร์ฟเวอร์ ทำ rate limit และกั้นด้วยรหัสผ่าน
แล้วให้หน้าเว็บ `fetch` ไป endpoint นั้นแทน — หน้าเว็บยังเป็น static เหมือนเดิม

## โจทย์ระดับแข่งขัน

ข้อที่ติดระดับ **แข่งขัน** จะแนบคำสั่งเพิ่มไปในพรอมป์ระบบว่าโจทย์แนวนี้มักต้องมองหาแง่มุม
หรือใช้หลายหัวข้อร่วมกัน ไม่ใช่แทนค่าลงสูตร — คำใบ้ขั้นต้นจึงให้ชวนน้องสังเกตรูปแบบ
หรือลองกรณีเล็ก ๆ ก่อน ห้ามรีบบอกว่าให้ใช้สูตรอะไร และห้ามบอกว่ายากเกินไปสำหรับน้อง

## บันไดคำใบ้ 7 ขั้น

ขั้นของคำใบ้ = จำนวนครั้งที่ถามในข้อนั้น ยิ่งถามยิ่งละเอียดขึ้น

| ขั้น | พี่หลวงทำอะไร |
| ---: | --- |
| 1 | ถามว่าโจทย์ให้อะไรมาและกำลังหาอะไร (เช็กว่าอ่านโจทย์เข้าใจตรงกัน) |
| 2 | ชวนดูข้อมูล/หน่วย/เงื่อนไข แล้วถามว่านึกถึงหลักการอะไรที่เคยเรียน |
| 3 | บอก **ชื่อ** หลักการหรือสูตรที่เกี่ยวข้อง แต่ยังไม่แทนตัวเลขให้ |
| 4 | ชี้ว่าวิธีทำเริ่มพลาดที่บรรทัดไหน โดยใช้คำถามให้เห็นเอง |
| 5 | ทำขั้นแรกให้ดูเป็นตัวอย่าง แล้วให้ทำขั้นต่อไปเอง |
| 6 | เดินวิธีทำเกือบครบ เว้นการคำนวณขั้นสุดท้ายไว้ให้ทำเอง |
| 7 | เฉลยเต็มพร้อมคำตอบ สรุปหลักการ และโจทย์คล้าย ๆ ให้ลองอีก 1 ข้อ |

ขั้นที่ 1–6 **ห้ามบอกคำตอบสุดท้าย** ถึงจะถูกขอก็ตาม · ถ้าถูกขอให้เฉลย พี่หลวงจะปฏิเสธ
อย่างเป็นมิตรแล้วถามคำถามนำข้อถัดไป

**ขั้นที่ 7 ต้องปลดล็อกเฉลยด้วยรหัสผ่านก่อน** (`ANSWER_PASSWORD` เดียวกับปุ่ม “ดูเฉลย”)
ไม่งั้นบันไดจะหยุดที่ขั้น 6 — ไม่อย่างนั้นถามพี่หลวง 7 ครั้งก็ข้ามรหัสผ่านเฉลยได้

กด **“เริ่มบทสนทนาใหม่”** เพื่อล้างบทสนทนาของข้อนั้นและเริ่มนับขั้นใหม่จาก 1

## สมการและรูปวาด

คำตอบของพี่หลวงไม่ได้แสดงเป็นข้อความดิบ แต่ผ่านตัวเรนเดอร์เล็ก ๆ ในหน้าเว็บก่อน

**สมการ** — `2^2` กลายเป็น 2² จริง ๆ (`<sup>`), `x_1` เป็นตัวห้อย, `3/4` เป็นเศษส่วนซ้อนสองชั้น,
`<=` `>=` `!=` เป็น ≤ ≥ ≠, `*` ระหว่างตัวเลขเป็น × และถ้าพี่หลวงเผลอเขียน LaTeX
(`\(...\)`, `\frac{a}{b}`, `$...$`) จะถูกแปลงกลับเป็นรูปแบบข้างต้นให้ ไม่ใช่โชว์แบ็กสแลชทิ้งไว้

**รูปวาด** — พี่หลวงแนบ SVG มาในคำตอบได้ เพื่อให้น้องเห็นภาพ **เฉพาะข้อที่จำเป็น**
เช่น รูปเรขาคณิต · เส้นจำนวน · เศษส่วนเป็นรูป · มุม · กราฟ · รูปคลี่
พรอมป์สั่งไว้ชัดว่าโจทย์คำนวณล้วน ๆ ไม่ต้องวาด และห้ามวาดซ้ำรูปที่โจทย์มีอยู่แล้ว

รูปที่ส่งกลับมา **ไม่ถูกยัดเข้า `innerHTML` ตรง ๆ** เพราะ SVG รันสคริปต์ได้ และหน้านี้เก็บ
API key ไว้ใน `localStorage` ของ origin เดียวกัน — จึงผ่าน `sanitizeSvg()` ที่แจงด้วย
`DOMParser` แล้ว **สร้างโหนดขึ้นใหม่ทีละตัวจากรายการที่อนุญาต** (`createElementNS`)

| ผ่าน | ไม่ผ่าน |
| --- | --- |
| `svg g line polyline polygon rect circle ellipse path text tspan defs marker title desc` | แท็กอื่นทั้งหมด — `script` `style` `image` `use` `foreignObject` `a` `animate` `set` |
| แอตทริบิวต์เรขาคณิต/การแสดงผลในรายการอนุญาต | `on*` ทุกตัว · แอตทริบิวต์ในเนมสเปซอื่น (`xlink:*`) · ค่าใด ๆ ที่มี `<` `>` |
| `fill="url(#arrow)"` ที่ชี้ไป `<marker>` ในรูปเดียวกัน | `url()` ที่ชี้ออกนอกรูป · `javascript:` · ลิงก์ทุกชนิด |

จำกัดไว้ที่ 8000 ตัวอักษรและ 400 โหนดต่อรูป · รูปที่แจงไม่ผ่านจะขึ้นเป็นกล่อง
“⚠️ รูปประกอบนี้แสดงไม่ได้” แทนการเงียบหาย · ระหว่างสตรีม SVG ที่ยังมาไม่ครบจะยังไม่เรนเดอร์
แต่ขึ้น “🖊️ กำลังวาดรูป…” ไว้ก่อน

`tools/dom_test.cjs` มีชุดทดสอบยิงเพย์โหลดโจมตี 10 แบบใส่ตัวกรองนี้ทุกครั้งที่รัน

## ข้อจำกัดที่รู้อยู่

- **ข้อที่มีรูปประกอบ (114 ข้อ)** — โมเดลไม่เห็นรูป SVG จึงแทนที่ด้วยเครื่องหมาย `⟪รูปประกอบ⟫`
  ในโจทย์ที่ส่งไป และสั่งให้พี่หลวง *ถาม* น้องว่าอ่านค่าอะไรได้จากรูปแทนการเดา
  ถ้าจะให้ดีขึ้นควรเพิ่มฟิลด์ `figalt` (คำบรรยายรูปสั้น ๆ) ในคลังข้อสอบแล้วส่งไปด้วย
- ตัวเรนเดอร์สมการเป็นของทำเอง ไม่ใช่ MathJax/KaTeX จึงรับได้แค่รูปแบบที่พบบ่อย
  (ยกกำลัง · ตัวห้อย · เศษส่วน · ราก · เครื่องหมายเปรียบเทียบ) ยังไม่รองรับเมทริกซ์
  อินทิกรัล หรือซัมเมชัน — ระดับ ม.1–ม.3 ยังไม่ต้องใช้
- โจทย์ · เฉลย · วิธีทำ ถูกส่งออกไปนอกเครื่องทุกครั้งที่ถาม (ดูตารางด้านบน)
