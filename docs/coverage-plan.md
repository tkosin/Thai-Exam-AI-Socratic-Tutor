## Schema ของข้อสอบ

```js
{
  unit: 9,                     // หมายเลขหน่วย 1-9
  uname: "สถิติ",              // ชื่อหน่วย
  sub: "แผนภูมิแท่ง",          // ประเภทข้อสอบ (ใช้เป็นตัวกรอง)
  text: "…",                   // โจทย์ (รองรับ HTML: ตาราง, SVG, ตัวเลือก ก-ง)
  answer: "50",                // เฉลย (รองรับ HTML)
  level: "ง่าย",               // ง่าย | กลาง | ยาก
  std: "ค 3.1 ม.1/1",          // ตัวชี้วัด ("-" ถ้าไม่ใช่ตัวชี้วัด ม.1)
  tag: "ม.1"                   // ม.1 | ทบทวน ป.6 | ต่อยอด ม.2
}
```

**หลักการเขียนเฉลยให้ระบบตรวจอัตโนมัติทำงานได้**

- คำตอบควรเป็น **ตัวเลข** เป็นอันดับแรก (`50`, `-41`, `7/12`)
- ถ้าเป็นข้อความ ให้ใช้คำสั้นและคำเดียว (`วงกลม`, `ศุกร์`, `ชมพู่`)
- ถ้าต้องเทียบรูปภาพ ให้ทำเป็น **ตัวเลือก ก-ง** แล้วเฉลยเป็นตัวอักษรตัวเดียว (`ข`)
- ถ้ามีคำตอบที่ยอมรับได้หลายแบบ ให้คั่นด้วยคำว่า `หรือ` เช่น `รูปสี่เหลี่ยมผืนผ้า หรือ สี่เหลี่ยมมุมฉาก`
- เลี่ยงเฉลยเชิงบรรยายยาว (>40 ตัวอักษร) เพราะระบบจะตรวจไม่ได้ และแจ้งผู้เรียนว่าให้เทียบเฉลยเอง

## วิธีเพิ่มข้อสอบ

รูปประกอบทั้งหมดเป็น **inline SVG** ในฟิลด์ `text` — ไม่พึ่งไฟล์ภายนอก เปิดออฟไลน์และสั่งพิมพ์ได้

```bash
# 1) เขียนโจทย์ชุดใหม่ตามรูปแบบของ tools/phase1b_questions.py
python3 tools/phase1b_questions.py             # -> questions/phase1b.json

# 2) รวมเข้า index.html (แทรกตามลำดับหน่วย + เติม std/tag/level ให้ข้อเดิม)
python3 tools/merge_into_html.py questions/phase1b.json

# 3) ซิงค์สำเนาชื่อภาษาไทย
cp index.html ข้อสอบคณิตศาสตร์_ม1.html

# 4) ตรวจก่อน commit (CI รันชุดเดียวกันนี้)
python3 tools/validate.py
npm install jsdom --no-save && node tools/dom_test.cjs
```
