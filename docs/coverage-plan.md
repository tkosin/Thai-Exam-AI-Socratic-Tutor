## Schema ของข้อสอบ

```js
{
  unit: 9,                     // หมายเลขหน่วย (อยู่ที่หัวไฟล์ ไม่ต้องเขียนซ้ำทุกข้อ)
  uname: "สถิติ",              // ชื่อหน่วย (อยู่ที่หัวไฟล์เช่นกัน)
  sub: "แผนภูมิแท่ง",          // ประเภท/ชุดข้อสอบ (ใช้เป็นตัวกรอง)
  text: "…",                   // โจทย์ (รองรับ HTML: ตาราง, SVG, ตัวเลือก ก-ง)
  answer: "50",                // เฉลย (รองรับ HTML)
  level: "ง่าย",               // ง่าย | กลาง | ยาก
  std: "ค 3.1 ม.1/1",          // ตัวชี้วัด ("-" ถ้าไม่ผูกกับตัวชี้วัดใดตัวเดียว)
  tag: "ม.1"                   // ม.1 | ม.2 | ทบทวน ป.6 | ต่อยอด ม.2
}
```

> `subject` และ `grade` **ไม่ต้องเขียนในข้อสอบ** — `tools/build.py` เติมให้จาก
> `questions/courses.json` ตามโฟลเดอร์ที่ไฟล์นั้นอยู่

**หลักการเขียนเฉลยให้ระบบตรวจอัตโนมัติทำงานได้**

- คำตอบควรเป็น **ตัวเลข** เป็นอันดับแรก (`50`, `-41`, `7/12`)
- ถ้าเป็นข้อความ ให้ใช้คำสั้นและคำเดียว (`วงกลม`, `ศุกร์`, `ชมพู่`)
- ถ้าต้องเทียบรูปภาพ ให้ทำเป็น **ตัวเลือก ก-ง** แล้วเฉลยเป็นตัวอักษรตัวเดียว (`ข`)
- ถ้ามีคำตอบที่ยอมรับได้หลายแบบ ให้คั่นด้วยคำว่า `หรือ` เช่น `รูปสี่เหลี่ยมผืนผ้า หรือ สี่เหลี่ยมมุมฉาก`
- เลี่ยงเฉลยเชิงบรรยายยาว (>40 ตัวอักษร) เพราะระบบจะตรวจไม่ได้ และแจ้งผู้เรียนว่าให้เทียบเฉลยเอง

| `parallel_lines` | เส้นขนานถูกตัดด้วยเส้นตัด พร้อมมุมแย้งและมุมภายในข้างเดียวกัน |
